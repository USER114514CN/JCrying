欢迎使用 JCrying Tool! JCrying Tool 是一个用于编码、解码、加密、解密数据的工具。

JCrying 的交互方式是通过命令行界面进行操作。

帮助

在 JCrying 中，您可以使用以下命令进行操作：

  • encode: 用于编码数据。
  • decode: 用于解码数据。
  • encrypt: 用于加密数据。
  • decrypt: 用于解密数据。

每个命令都有其特定与通用的参数和选项。

参选项数
  • --help -h: 显示帮助信息
  • --version -v: 显示版本信息
  • --available-encoder -aE: 显示可用的编码器列表
  • --available-encryptor -aX: 显示可用的加密器列表
encode/decode 参数
  • --encoder -X: 指定编码器类型
  • --decoder -X: 指定解码器类型
  • --text -T: 指定要编码/解码的文本(语法 --text key=value 或 -Tkey=value)
  • --file -f: 指定输入文件路径
  • --write-file -w: 指定输出文件路径
  • --url -u: 自动从 URL 获取数据并传入编/解码器, 支持的协议有 http, https, ftp, file, data 等
  • --info -I: 显示编码/解码信息
  • --streaming -S: 启用流式处理, 这会显著降低程序在处理时所占用的运行时内存
  • --streaming-buffer-size -B: 指定流式处理的缓冲区大小(单位: 字节)。这与程序处理数据占用的运行时内存成正相关, 处理速度成负相关, 默认 4MB
  • --options -O: 指定编/解码器的选项，
encrypt/decrypt 参数
  • --encryptor -X: 指定加密器类型
  • --decryptor -X: 指定解密器类型
  • --key-text -kT: 指定加密/解密的文本密钥(语法--key-text key=value 或 -kTkey=value)
  • --key-hex -kH: 指定加密/解密的十六进制密钥(语法--key-hex key=value 或 -kHkey=value)
  • --key-file -kF: 指定加密/解密的密钥文件路径
  • --file -f: 指定输入文件路径
  • --write-file -w: 指定输出文件路径
  • --url -u: 自动从 URL 获取数据并传入加/解密器, 支持的协议有 http, https, ftp, file, data 等
  • --info -I: 显示加密/解密信息
注意: 以上参数和选项的使用方式如与 --help 选项的文档冲突, 请以 --help 选项的文档为准。

使用示例

以下是一些使用 JCrying Tool 的示例命令：

  • 帮助
    jcrying --help
  • Base64编码Hello, World!
    jcrying encode --encoder b64 "-Ttext=Hello, World!"
  • Base64解码Hello, World!
    jcrying decode --decoder b64 "-Ttext=SGVsbG8sIFdvcmxkIQ=="
  • 十六进制编码非 ASCII 字符
    jcrying encode --encoder hex "-Ttext=非 ASCII 字符" -Tencoding=UTF-8
  • 从example.com获取数据并使用XOR异或加密
    jcrying encrypt --encryptor xor "-kTkey=your_secret_key" --url "http://example.com/data.txt"
  • 使用 AES 对 mysterious_image.png 加密到 mysterious_image_encrypted.png
    jcrying encrypt --encryptor aes -kTkey=length_must_be_16_24_32_bytes000 --file "path/to/mysterious_image.png" --write-file "path/to/mysterious_image_encrypted.png"
